## Evidence required before promotion

Promoting a row to verified requires a separately authorized and independently reviewed packet containing:

- exact network and program deployment identity;
- deployed-bytecode and reviewed-source relationship;
- upgrade-authority state;
- namespace config and auth account state;
- collection metadata and authority state;
- relevant transaction and finality evidence;
- owning external repository, commit, tree, and accepted integration source;
- production build and release provenance;
- current maintainer acceptance; and
- approved wording for any public claim.

## Source and product separation

The OGAL repository owns reviewed protocol source behavior only. An external product owns its gameplay, JSON schema, identity, privacy, custody, transfer, recovery, correction, business, economy, and public availability policies. Token possession and a namespace listing do not establish any of those policies.

Adding, changing, or promoting a namespace claim requires a separate Human-authorized source and evidence task. This candidate does not verify or publish a live namespace.
